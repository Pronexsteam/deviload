Microsoft Edge WebView2 SDK
===========================

Files: Microsoft.Web.WebView2.Core.dll, Microsoft.Web.WebView2.Wpf.dll, WebView2Loader.dll

These libraries come from the NuGet package "Microsoft.Web.WebView2"
(https://www.nuget.org/packages/Microsoft.Web.WebView2). They are distributed
under the Microsoft Software License Terms that accompany the package
(LICENSE.txt inside the .nupkg; also shown on the NuGet page under "License").

Deviload does not modify these files. setup-webview2.bat downloads the package
from NuGet and copies the three DLLs next to the application. The WebView2
Runtime itself (the browser engine) is part of Windows 10/11 or is installed
separately from https://developer.microsoft.com/microsoft-edge/webview2/.
