# Screenshots

The `*-2.7.8.png` images are captures of the app's actual frontend with controlled demonstration data. The geometric album covers, artist names, tracks and lyric text are original sample content, not a live catalog or a claim that a particular song provides word timings. The mini-player and phone remote use the same UI files as the application. No active pairing token or personal listening history is included.

The `downloads-2.9.0.png` capture shows three real MP3 downloads made in a test profile; `convert-2.9.0.png` shows the converter before a file is chosen. The `music-*-2.9.0.png` images show Devil Music with a test profile built from the live catalog: real album artwork, a few lines of synced lyrics and their MyMemory translation. They were captured from an isolated debug build; window controls are hidden and no personal library or pairing token is included.

Captured at 1600 × 1000 for the desktop, 380 × 112 logical pixels at 2× scale for the mini-player, and 390 × 844 for the phone. The remote is a mobile browser view; it does not play music on the phone. The converter capture shows its initial state before choosing a file.

Older, unversioned screenshots are retained for historical references and are not used to illustrate the current README.
